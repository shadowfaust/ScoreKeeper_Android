Score Keeper v1.0.0

A simple and lightweight Android scorekeeping application.

Features

- Track scores for two teams.
- Add or subtract points.
- Custom team names.
- Target score tracking.
- Simple and clean interface.
- Works completely offline.

Installation

1. Download "Score-Keeper.apk".
2. Open the downloaded file.
3. Allow installation from this source if Android asks.
4. Install and enjoy!
